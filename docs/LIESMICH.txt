Keystead – Schnellstart
=======================

Keystead ist ein lokaler Passwort-Manager. Alle Daten bleiben verschlüsselt auf
diesem Rechner – es gibt keinen Server und keine Cloud.
(Keystead = Key + Homestead: deine Schlüssel bleiben zu Hause.)

1. Starten
----------
Keystead.exe doppelklicken. Beim ersten Start einen Tresor anlegen und ein
starkes Master-Passwort wählen. Danach am besten gleich einen
Wiederherstellungsschlüssel erstellen und sicher aufbewahren – ohne ihn ist ein
vergessenes Master-Passwort NICHT wiederherstellbar.

Windows-SmartScreen-Hinweis: Die EXE ist nicht signiert. Falls „Der Computer
wurde durch Windows geschützt“ erscheint: „Weitere Informationen“ →
„Trotzdem ausführen“.

Alte VaultX-1.x-Tresore: beim ersten Start „Von VaultX umsteigen“ wählen oder
später unter Einstellungen → Import & Export → Importieren.

Speicherort der Daten: %LOCALAPPDATA%\Keystead
Portabler Modus (Daten neben der EXE): Einstellungen → Erweitert → Portabler
Modus, oder einfach einen Ordner "Keystead-Data" neben Keystead.exe anlegen.

2. Browser-Erweiterung (Chrome, Edge, Brave)
--------------------------------------------
a) In Keystead: Einstellungen → Browser-Integration → beim Browser „Aktivieren“.
b) Im Browser chrome://extensions (bzw. edge://extensions) öffnen,
   „Entwicklermodus“ einschalten, „Entpackte Erweiterung laden“ und den Ordner
   "browser-extension" aus diesem ZIP auswählen.
   Erwartete Erweiterungs-ID: imfndemblnaalppnmdplagajjielnaok
c) Auf das Keystead-Symbol in der Browserleiste klicken →
   „Mit Keystead verbinden“ → den angezeigten Code in der App bestätigen.

Wichtig: Den Ordner "browser-extension" nach dem Laden nicht verschieben oder
löschen – der Browser lädt die Erweiterung von dort. Wenn du Keystead.exe
verschiebst, einfach einmal Keystead starten; die Registrierung wird automatisch
aktualisiert.

3. Terminal-Version
-------------------
In der App: Einstellungen → Erweitert → „Terminal öffnen“.
Oder in einer Konsole: keystead-cli.exe  (Hilfe: keystead-cli.exe --help)
